Trajectory Timing Calibrator

Fits simulator timing parameters to match delivered trajectory logs (sampled ~20ms) by minimizing the error between predicted and measured cumulative time along the control point MU axis. Inputs: - Plan: JSON exported by ESAPI launcher or by "Export Parsed Data as JSON" in the simulator. - Log: either (A) CSV/TSV text with a time column and a cumulative MU/meterset column, or (B) Varian TrueBeam Trajectory Log binary (`.bin`) (parsed using the same field order as `pylinac.TrajectoryLog`).
